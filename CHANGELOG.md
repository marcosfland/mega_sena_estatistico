# Changelog

## [1.4.0] - 2025-12-28
### Melhorias
- Modularização completa do projeto (CLI, GUI, análise, banco).
- Expansão dos testes automatizados para todos os módulos.
- Interface gráfica modernizada, com feedback visual aprimorado e gráficos interativos.
- Cache e tratamento de erros de banco otimizados.
- Filtros avançados e visualização dinâmica dos dados.
- Atualização do requirements.txt e documentação detalhada.

### Correções
- Correção de erros de importação e modularização.
- Ajustes em funções estatísticas e banco de dados.

### Novos recursos
- Gráficos interativos integrados à GUI.
- Função de retry automático para operações de banco.
- Tooltips e layout moderno na interface.
